# midve-environment

This will store all my current configurations.

You can find every configuration you need in my distributed structure.

`./install.sh` symlinks the live configs (`~/.config/niri`, waybar, mako, rofi,
kitty, ...) to this repo, so the repo is the only copy. It is safe to re-run;
anything already in the way is moved to `<path>.bak-<date>`.

My current stack:
```bash
Compositor: Niri + Wayland
Shell: zsh
Terminal: kitty
OS: Gentoo Linux
```
